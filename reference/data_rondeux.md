# Example dataset for using GCubeR

An inventory dataset in the Bois Jacques Rondeux in Gembloux (Belgium,
Wallonia). Data were collected during a student project from Gembloux
AgroBio Tech

## Usage

``` r
data(data_rondeux)
```

## Format

A data frame with columns:

- id_tree:

  Unique ID of the tree (integer)

- species:

  Latin name of the species (character)

- species_code:

  Species code in GCubeR (character)

- c150:

  Circumference of the tree at 1m50 (numeric, cm)

- htot:

  Total height of the tree (numeric, m)
