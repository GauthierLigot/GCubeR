# Vallet coefficients for merchantable volume (vc22)

Species-specific polynomial coefficients (a, b, c) used in the Vallet
model to compute commercial wood volume (vc22) up to a 7 cm top
diameter.

## Usage

``` r
data(val_vc22)
```

## Format

A data frame with columns:

- species_code:

  Tree species code (character)

- coeff_a:

  Coefficient a (numeric)

- coeff_b:

  Coefficient b (numeric)

- coeff_c:

  Coefficient c (numeric)

## Source

Internal CSV file `data-raw/vallet_vc22.csv`
